Henkel · GenAI pilot

GenAI content at speed, with governance built in

I set up the pilot and the rules it ran by, so brand teams could use GenAI in real campaigns.

60-70%Less asset production time
14Assets in the first wave
2Consumer segments

What I did

  • Initiated the GenAI pilot and set up its governance.
  • Built it around copy and asset generation in the modules of a flexible template, plus segment scoring analysis.
  • Ran it in one pilot market, used by the brand teams, on high-churn segments with zero margin dilution from the promotions offered, starting with 7 assets for each of two segments.

The result

Asset production time fell by 60 to 70%, which sped up campaigns.

Human in the loop

A person stayed in the loop at every stage:

  1. Segment definition
  2. Rule definition
  3. Modular template creation
  4. Generative prompts and loops
  5. Asset integration pre-flight
  6. Review of each of the 14 templates before flight

Why governance came first

Generated content only reaches real campaigns if brand, legal and data owners trust it. Setting the rules at the start is what let the pilot move from experiment to working practice.
